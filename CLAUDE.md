# Instruktioner för Claude

## Pull requests

- När en ändring är klar: committa, pusha, skapa en pull request mot `main` och merga den direkt, utan att fråga först.
- Merga bara om PR:en går att merga (ingen konflikt, CI grön om det finns CI). Annars: åtgärda problemet först eller berätta vad som stoppar.
